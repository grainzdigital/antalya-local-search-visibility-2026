# Antalya Local Search Visibility Benchmark 2026

Open research by **Grainz Digital**.

**60 anonymized local-business observations · 18 sectors · Antalya, Türkiye · captured 2026-08-24**

## Why this exists
Local SEO advice often uses generic thresholds. This dataset provides a small, transparent and reproducible benchmark based on businesses surfaced prominently in local-search style discovery across multiple Antalya sectors.

## Key findings
- Median displayed rating: **4.8**
- Rated observations ≥4.5: **88.1%**
- Rated observations ≥4.8: **54.2%**
- Median review count: **188**
- Address visible: **100.0%**
- Phone visible: **96.7%**
- Hours visible: **90.0%**
